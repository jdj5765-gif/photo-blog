# 사진 → 블로그 초안 생성기

사진을 올리면 Claude가 SEO 최적화된 한국어 리뷰 초안을 써주는 웹앱입니다.
발행 기능은 없고, 결과를 **복사 / .md 다운로드**해서 네이버 블로그 등에 붙여넣는 방식입니다.

## 실행

```bash
cp .env.local.example .env.local   # 그리고 ANTHROPIC_API_KEY 채우기
npm install
npm run dev
```

http://localhost:3000

## 글이 나오는 순서

참고 글(을지로 대동옥 리뷰)의 구성을 그대로 따릅니다.

1. **핵심 포인트 불릿** — "야장하기 좋은 맛집", "콜키지 프리 맛집" 처럼 한 줄씩
2. 도입 + 야장/가게 분위기
3. 웨이팅 / 캐치테이블 예약 · 대기 공간
4. 메뉴 (사진 위치 `[사진N]` 표기)
5. 단체모임 / 회식
6. "이런 점이 좋았습니다" (네이버 키워드 요약) → 총평

## 네이버 키워드 리뷰 처리

네이버 플레이스 키워드 41개(음식/가격 · 분위기 · 기타)를 화면에서 고를 수 있습니다.

- **아무것도 안 고르면** → AI가 사진을 보고 근거가 보이는 항목만 5~8개 직접 선택
- **고르면** → 고른 건 필수 반영 + AI가 사진 근거로 2~4개 추가

선택된 키워드는 세 군데에 들어갑니다.

| 위치 | 형태 |
|---|---|
| 제목 | 명사형으로 변환 — "단체모임 하기 좋아요" → `단체모임 맛집` |
| 본문 | 어울리는 섹션 안에서 근거와 함께 서술 |
| 총평 직전 | "이런 점이 좋았습니다" 불릿 요약 |

## 추천 제목

결과 상단에 **추천 제목 3개**가 별도 카드로 뜹니다. 각각 글자 수와 복사 버튼이 붙어 있고,
`[지역 맛집] 상호 / 상황키워드 / 메뉴키워드` 형태로 서로 다른 키워드 조합을 씁니다.

## 화면에서 조절하는 것

| 항목 | 설명 |
|---|---|
| 사진 | 최대 10장. 업로드 시 자동으로 1568px로 리사이즈됩니다 |
| 상단 핵심 포인트 | 글 맨 위 불릿. 프리셋 선택 + 직접 추가 |
| 네이버 키워드 리뷰 | 위 설명 참고 |
| 확인된 정보 | **여기 적은 것만 사실로 씁니다.** 나머지는 빈칸 `____`로 남김 (글당 최대 5개) |

## 파일 구조

```
src/
  app/
    page.tsx                 화면 전체 (업로드 · 옵션 · 추천 제목 · 결과)
    api/generate/route.ts    Claude 호출 (스트리밍). API 키는 서버에만 존재
  lib/
    style-guide.ts           ★ 참고 글에서 추출한 스타일 규칙 — 여기만 고치면 톤이 바뀝니다
    naver-keywords.ts        네이버 키워드 리뷰 전체 목록 · 핵심 포인트 프리셋
    prompt.ts                위 두 개를 조립해 프롬프트 생성
```

## 톤을 바꾸고 싶을 때

`src/lib/style-guide.ts`의 `STYLE_GUIDE` 문자열만 수정하면 됩니다.
참고 글을 통째로 흉내내고 싶으면 같은 파일의 `REFERENCE_EXAMPLES` 배열에 원문을 넣으세요
(모방도는 올라가지만 요청당 토큰 비용이 늘어납니다).

## 주의

  발행 전 그 부분을 반드시 채워주세요.
